# 🌸 Perfume Shop – Full Stack Web Application

## 📌 Project Overview
**Perfume Shop** is a full-stack web application developed to showcase and manage perfume products through a modern user interface and a robust backend system.  
The project includes a **frontend**, **backend APIs**, and **MongoDB database integration**, making it a complete MERN-style application.

This project demonstrates practical implementation of **full-stack web development concepts**, including RESTful APIs and database connectivity.
